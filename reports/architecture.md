# SkillLens AI Architecture

## Overview

SkillLens AI is a workforce intelligence and career analytics platform. It combines data ingestion, skill extraction, analytics, machine learning, CV matching, API services and dashboarding.

The project is designed to demonstrate skills across data science, data engineering, backend development, analytics engineering and system architecture.
